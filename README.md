# SubTracker — управление цифровыми подписками и расходами

Курсовой проект по дисциплине «Разработка веб-приложений».
Тема: «Разработка веб-приложения для управления цифровыми подписками и расходами».
Автор: Серокуров Михаил Романович, группа 241-3211.

## Возможности

- регистрация, вход и личный кабинет (вход по email, роли «Пользователь» и «Администратор»);
- CRUD подписок: сервис, категория, стоимость, валюта, период оплаты (неделя / месяц / квартал / год), пробный период;
- управление жизненным циклом подписки: активация, приостановка, отмена, отметка об оплате;
- автоматическая фиксация списаний по расписанию и история расходов (CRUD платежей);
- мультивалютность: RUB, USD, EUR с пересчётом по курсу;
- календарь списаний на 30 дней и уведомления (скорое списание, конец пробного периода, превышение бюджета);
- аналитика: динамика по месяцам, структура по категориям, самые затратные подписки, сравнение с прошлым периодом;
- выгрузка отчёта в CSV и Excel;
- панель администратора: статистика, пользователи и роли, справочники категорий и валют.

## Стек

Python 3.12, Django 5, MySQL 8 (резервный режим — SQLite), HTML, CSS, JavaScript, Bootstrap 5, Chart.js, Docker.

## Структура проекта

| Папка | Назначение |
|---|---|
| `config/` | настройки проекта (`settings.py`), главные маршруты (`urls.py`) |
| `accounts/` | модель пользователя, регистрация, вход, профиль, декоратор `admin_required` |
| `subscriptions/` | модели Currency, Category, Subscription, Payment, Notification; бизнес-логика в `services.py`; CRUD-представления |
| `analytics/` | расчёты для аналитики (`services.py`), страница графиков, выгрузка CSV/Excel |
| `management_panel/` | панель администратора: статистика, пользователи, справочники |
| `templates/` | HTML-шаблоны Django |
| `static/` | CSS, JavaScript, Bootstrap и Chart.js (подключены локально) |

## Быстрый запуск (без MySQL)

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env          # в Linux/macOS: cp .env.example .env
python manage.py migrate
python manage.py load_demo_data
python manage.py runserver
```

Открыть http://127.0.0.1:8000/

## Запуск с MySQL через Docker

```bash
docker compose up --build
```
